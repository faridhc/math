🔢 Арифметика

Что это: Арифметика — раздел математики о числах и простейших действиях: сложение, вычитание, умножение, деление.

Свойства действий

Переместительный законa + b = b + a a · b = b · a
От перестановки слагаемых (множителей) сумма (произведение) не меняется.
Сочетательный закон(a + b) + c = a + (b + c) (a · b) · c = a · (b · c)
Распределительный законa · (b + c) = a·b + a·c

Степени

Свойства степенейaᵐ · aⁿ = aᵐ⁺ⁿ aᵐ : aⁿ = aᵐ⁻ⁿ (aᵐ)ⁿ = aᵐⁿ (ab)ⁿ = aⁿ·bⁿ (a/b)ⁿ = aⁿ/bⁿ a⁰ = 1 (a ≠ 0) a⁻ⁿ = 1/aⁿ
Пример: 2³ · 2² = 2⁵ = 32

Корни

Свойства корней√(a·b) = √a · √b √(a/b) = √a / √b (√a)² = a ⁿ√(aᵐ) = aᵐ/ⁿ √a = a^(1/2)

Модуль

Модуль — расстояние от числа до нуля. Всегда неотрицательный.
|a| = a, если a ≥ 0 |a| = -a, если a < 0 |a·b| = |a|·|b| |a + b| ≤ |a| + |b|
Пример: |−5| = 5, |3| = 3

Множества чисел

ℕ — натуральные (1, 2, 3, ...) ℤ — целые (..., −2, −1, 0, 1, 2, ...) ℚ — рациональные (дроби) ℝ — действительные (все числа на прямой) ℂ — комплексные ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ

➗ Дроби

Дробь — это число вида ab, где a — числитель, b — знаменатель (b ≠ 0).

Основное свойство дроби

Основное свойствоab = a·cb·c
Если числитель и знаменатель умножить (или разделить) на одно и то же число, дробь не изменится.
Пример: 12 = 24 = 50100

Сложение и вычитание

Одинаковые знаменателиac + bc = a + bc
Разные знаменателиab + cd = a·d + b·cb·d
Пример: 12 + 13 = 3 + 26 = 56

Умножение и деление

Умножениеab · cd = a·cb·d
Делениеab : cd = a·db·c
Пример: 12 : 14 = 1·42·1 = 2

Смешанное число

Переводa bc = a·c + bc
Пример: 2 13 = 73

Сравнение дробей

Сравнениеab > cd ⇔ a·d > b·c
Приводим к общему знаменателю или перемножаем крест-накрест.

🔗 НОК и НОД

НОД — наибольший общий делитель. Самое большое число, на которое делятся оба числа.
НОК — наименьшее общее кратное. Самое маленькое число, которое делится на оба числа.

Как найти НОД

Способ 1: Разложение1. Разложить числа на простые множители 2. Взять общие множители в наименьшей степени 3. Перемножить
Пример: НОД(12, 18)
12 = 2² · 3
18 = 2 · 3²
Общие: 2¹ · 3¹ = 6

Как найти НОК

Способ 1: Разложение1. Разложить числа на простые множители 2. Взять все множители в наибольшей степени 3. Перемножить
Пример: НОК(12, 18)
12 = 2² · 3
18 = 2 · 3²
Все: 2² · 3² = 36

Связь НОД и НОК

Главная формулаНОД(a, b) · НОК(a, b) = a · b
Произведение НОД и НОК двух чисел равно произведению самих чисел.
Проверка: НОД(12,18) · НОК(12,18) = 6 · 36 = 216 = 12 · 18 ✓

Алгоритм Евклида

Быстрый способ для НОДНОД(a, b) = НОД(b, a mod b) Пока b ≠ 0
Пример: НОД(48, 18)
48 mod 18 = 12
18 mod 12 = 6
12 mod 6 = 0
Ответ: 6

Взаимно простые числа

Взаимно простые — числа, у которых НОД = 1.
Пример: 8 и 9 — взаимно простые, НОД(8,9) = 1

➗ Алгебра

Алгебра — раздел математики, изучающий выражения с переменными, уравнения и неравенства.

Формулы сокращённого умножения

Квадрат суммы и разности(a + b)² = a² + 2ab + b² (a - b)² = a² - 2ab + b²
Разность квадратовa² - b² = (a - b)(a + b)
Куб суммы и разности(a + b)³ = a³ + 3a²b + 3ab² + b³ (a - b)³ = a³ - 3a²b + 3ab² - b³
Сумма и разность кубовa³ + b³ = (a + b)(a² - ab + b²) a³ - b³ = (a - b)(a² + ab + b²)
Квадрат трёхчлена(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ac
Пример: (x + 3)² = x² + 6x + 9

Квадратное уравнение

Квадратное уравнение — уравнение вида ax² + bx + c = 0, где a ≠ 0.
ДискриминантD = b² - 4ac
Корниx = (-b ± √D) / 2a
D > 0 — два корня, D = 0 — один корень, D < 0 — нет действительных корней.
Пример: x² - 5x + 6 = 0
D = 25 - 24 = 1
x₁ = (5+1)/2 = 3, x₂ = (5−1)/2 = 2

Теорема Виета

Сумма и произведение корнейx₁ + x₂ = -b/a x₁ · x₂ = c/a
Пример: x² - 5x + 6 = 0
x₁ + x₂ = 5, x₁ · x₂ = 6 → x₁ = 2, x₂ = 3

Неполные квадратные уравнения

ax² + bx = 0 ⇒ x(ax + b) = 0 ⇒ x₁ = 0, x₂ = -b/a ax² + c = 0 ⇒ x² = -c/a ax² = 0 ⇒ x = 0

Линейное уравнение

ax + b = 0 ⇒ x = -b/a (a ≠ 0)

Система уравнений (метод Крамера)

a₁x + b₁y = c₁ a₂x + b₂y = c₂ Δ = a₁b₂ - a₂b₁ x = (c₁b₂ - c₂b₁)/Δ y = (a₁c₂ - a₂c₁)/Δ

Неравенства

СвойстваЕсли a > b, то a + c > b + c Если a > b и c > 0, то ac > bc Если a > b и c < 0, то ac < bc

Неравенства с модулем

|x| < a ⇔ -a < x < a |x| > a ⇔ x < -a или x > a |x| ≤ a ⇔ -a ≤ x ≤ a |x| ≥ a ⇔ x ≤ -a или x ≥ a

Теорема Безу

P(x) = (x - a)·Q(x) + R P(a) = R

Разложение квадратного трёхчлена

ax² + bx + c = a(x - x₁)(x - x₂)

📐 Тригонометрия

Тригонометрия — раздел математики о соотношениях сторон и углов треугольника, а также о тригонометрических функциях.

Основные тождества

sin²α + cos²α = 1 tanα = sinα/cosα cotα = cosα/sinα tanα · cotα = 1 1 + tan²α = 1/cos²α 1 + cot²α = 1/sin²α

Сумма и разность углов

sin(α + β) = sinα·cosβ + cosα·sinβ sin(α - β) = sinα·cosβ - cosα·sinβ cos(α + β) = cosα·cosβ - sinα·sinβ cos(α - β) = cosα·cosβ + sinα·sinβ tan(α + β) = (tanα + tanβ)/(1 - tanα·tanβ) tan(α - β) = (tanα - tanβ)/(1 + tanα·tanβ)

Двойной угол

sin2α = 2sinα·cosα cos2α = cos²α - sin²α = 1 - 2sin²α = 2cos²α - 1 tan2α = 2tanα/(1 - tan²α)
Пример: sin60° = 2·sin30°·cos30° = 2·½·(√3/2) = √3/2

Половина угла

sin(α/2) = ±√((1 - cosα)/2) cos(α/2) = ±√((1 + cosα)/2) tan(α/2) = sinα/(1 + cosα) = (1 - cosα)/sinα

Тройной угол

sin3α = 3sinα - 4sin³α cos3α = 4cos³α - 3cosα

Произведение → сумма

sinα·cosβ = ½[sin(α+β) + sin(α-β)] cosα·cosβ = ½[cos(α-β) + cos(α+β)] sinα·sinβ = ½[cos(α-β) - cos(α+β)]

Сумма → произведение

sinα + sinβ = 2sin((α+β)/2)·cos((α-β)/2) sinα - sinβ = 2cos((α+β)/2)·sin((α-β)/2) cosα + cosβ = 2cos((α+β)/2)·cos((α-β)/2) cosα - cosβ = -2sin((α+β)/2)·sin((α-β)/2)

Формулы приведения

sin(90° - α) = cosα cos(90° - α) = sinα sin(180° - α) = sinα cos(180° - α) = -cosα sin(180° + α) = -sinα cos(180° + α) = -cosα sin(360° - α) = -sinα cos(360° - α) = cosα

Значения углов

sin0° = 0, cos0° = 1, tan0° = 0 sin30° = ½, cos30° = √3/2, tan30° = √3/3 sin45° = √2/2, cos45° = √2/2, tan45° = 1 sin60° = √3/2, cos60° = ½, tan60° = √3 sin90° = 1, cos90° = 0, tan90° — не существует

Теорема синусов

a/sinA = b/sinB = c/sinC = 2R

Теорема косинусов

c² = a² + b² - 2ab·cosC cosC = (a² + b² - c²)/2ab

Обратные функции

arcsinx + arccosx = π/2 arctanx + arccotx = π/2 arcsin(-x) = -arcsinx arccos(-x) = π - arccosx

Простейшие уравнения

sinx = a ⇒ x = (-1)ⁿ·arcsina + πn cosx = a ⇒ x = ±arccosa + 2πn tanx = a ⇒ x = arctana + πn cotx = a ⇒ x = arccota + πn

📊 Логарифмы

Логарифм — показатель степени, в которую надо возвести основание, чтобы получить данное число.
Определениеlogₐ b = c ⇔ aᶜ = b a > 0, a ≠ 1, b > 0 lg b = log₁₀ b ln b = log_e b
Пример: log₂ 8 = 3, т.к. 2³ = 8

Свойства

logₐ(x·y) = logₐx + logₐy logₐ(x/y) = logₐx - logₐy logₐ(xⁿ) = n·logₐx logₐ(ⁿ√x) = (1/n)·logₐx logₐ a = 1 logₐ 1 = 0 a^(logₐ b) = b

Переход к новому основанию

logₐ b = log_c b / log_c a logₐ b = 1 / log_b a

Показательные уравнения

aˣ = b ⇒ x = logₐ b aˣ = aʸ ⇒ x = y

Логарифмические уравнения

logₐ f(x) = logₐ g(x) ⇒ f(x) = g(x) при f(x) > 0, g(x) > 0

♾️ Пределы

Предел — значение, к которому стремится функция при приближении аргумента к некоторой точке.
Обозначениеlim(x→a) f(x) = L

Основные пределы

lim(x→0) sinx/x = 1 lim(x→0) tanx/x = 1 lim(x→0) (1 - cosx)/x² = ½ lim(x→0) (eˣ - 1)/x = 1 lim(x→0) ln(1 + x)/x = 1 lim(x→∞) (1 + 1/x)ˣ = e lim(x→0) (1 + x)^(1/x) = e

Свойства

lim(f ± g) = lim f ± lim g lim(f · g) = lim f · lim g lim(f / g) = lim f / lim g (lim g ≠ 0) lim(C · f) = C · lim f

Правило Лопиталя

lim f/g = lim f'/g' при 0/0 или ∞/∞

Непрерывность

f(x) непрерывна в точке a: lim(x→a) f(x) = f(a)

📈 Производные

Производная — скорость изменения функции. Показывает, как быстро меняется функция при изменении аргумента.
Определениеf'(x) = lim(Δx→0) [f(x+Δx) - f(x)]/Δx

Основные производные

(C)' = 0 (x)' = 1 (xⁿ)' = n·xⁿ⁻¹ (√x)' = 1/(2√x) (1/x)' = -1/x² (eˣ)' = eˣ (aˣ)' = aˣ·lna (lnx)' = 1/x (logₐx)' = 1/(x·lna) (sinx)' = cosx (cosx)' = -sinx (tanx)' = 1/cos²x (cotx)' = -1/sin²x (arcsinx)' = 1/√(1-x²) (arccosx)' = -1/√(1-x²) (arctanx)' = 1/(1+x²)

Правила дифференцирования

(u + v)' = u' + v' (u - v)' = u' - v' (u·v)' = u'v + uv' (u/v)' = (u'v - uv')/v² (C·u)' = C·u'

Сложная функция

[f(g(x))]' = f'(g(x)) · g'(x)
Пример: (sin(2x))' = cos(2x) · 2 = 2cos(2x)

Геометрический смысл

k = f'(x₀) — угловой коэффициент касательной y - f(x₀) = f'(x₀)(x - x₀) — касательная y - f(x₀) = -1/f'(x₀) · (x - x₀) — нормаль

Физический смысл

v(t) = s'(t) — скорость a(t) = v'(t) = s''(t) — ускорение

Экстремумы

f'(x) = 0 — критические точки f''(x) > 0 — минимум f''(x) < 0 — максимум f''(x) = 0 — точка перегиба

Возрастание и убывание

f'(x) > 0 — возрастает f'(x) < 0 — убывает

∫ Интегралы

Интеграл — операция, обратная производной. Позволяет находить площади, объёмы, суммы.
Неопределённый интеграл∫f(x)dx = F(x) + C F'(x) = f(x)

Основные интегралы

∫xⁿ dx = xⁿ⁺¹/(n+1) + C ∫(1/x) dx = ln|x| + C ∫eˣ dx = eˣ + C ∫aˣ dx = aˣ/lna + C ∫sinx dx = -cosx + C ∫cosx dx = sinx + C ∫(1/cos²x) dx = tanx + C ∫(1/sin²x) dx = -cotx + C ∫(1/√(1-x²)) dx = arcsinx + C ∫(1/(1+x²)) dx = arctanx + C ∫lnx dx = x·lnx - x + C

Свойства

∫(f + g) dx = ∫f dx + ∫g dx ∫C·f(x) dx = C·∫f(x) dx

Формула Ньютона-Лейбница

∫[a,b] f(x) dx = F(b) - F(a)

Интегрирование по частям

∫u dv = uv - ∫v du

Замена переменной

∫f(g(x))·g'(x) dx = ∫f(u) du u = g(x), du = g'(x)dx

Приложения

S = ∫[a,b] f(x) dx — площадь V = π∫[a,b] f²(x) dx — объём вращения L = ∫[a,b] √(1 + (f'(x))²) dx — длина дуги

🔷 Планиметрия

Планиметрия — раздел геометрии о фигурах на плоскости.

Треугольник

ПлощадьS = ½·a·h S = ½·a·b·sinC S = √(p(p-a)(p-b)(p-c)) (Герон) p = (a+b+c)/2 S = abc/(4R) S = p·r
Теоремыa² + b² = c² (Пифагор) a/sinA = b/sinB = c/sinC = 2R c² = a² + b² - 2ab·cosC

Равносторонний треугольник

Прямоугольный треугольник

Квадрат

Прямоугольник

Ромб

📉 Аналитическая геометрия

Аналитическая геометрия — раздел геометрии, где фигуры описываются уравнениями.
Расстояние между точкамиd = √((x₂-x₁)² + (y₂-y₁)²)
Середина отрезкаM = ((x₁+x₂)/2, (y₁+y₂)/2)
Деление отрезкаx = (x₁ + λx₂)/(1 + λ) y = (y₁ + λy₂)/(1 + λ)

Уравнение прямой

y = kx + b k = (y₂-y₁)/(x₂-x₁) y - y₁ = k(x - x₁)

Взаимное расположение

Параллельны: k₁ = k₂ Перпендикулярны: k₁·k₂ = -1 Угол: tanθ = |(k₂-k₁)/(1+k₁k₂)|

Расстояние от точки до прямой

d = |Ax₀ + By₀ + C|/√(A² + B²) Прямая: Ax + By + C = 0

Окружность

(x-a)² + (y-b)² = R² Центр: (a, b), радиус: R

Эллипс

x²/a² + y²/b² = 1 c² = a² - b² e = c/a

Гипербола

x²/a² - y²/b² = 1 c² = a² + b²

Парабола

y² = 2px y = ax² + bx + c Вершина: x = -b/2a

➡️ Векторы

Вектор — направленный отрезок, имеющий длину и направление.
Координатыa = (x₁, y₁) b = (x₂, y₂)
Сложение и вычитаниеa + b = (x₁+x₂, y₁+y₂) a - b = (x₁-x₂, y₁-y₂)
Умножение на числоk·a = (kx₁, ky₁)
Длина вектора|a| = √(x₁² + y₁²)
Скалярное произведениеa·b = x₁x₂ + y₁y₂ a·b = |a|·|b|·cosθ
Угол между векторамиcosθ = (a·b)/(|a|·|b|)
УсловияПараллельны: x₁/x₂ = y₁/y₂ Перпендикулярны: x₁x₂ + y₁y₂ = 0
В пространствеa = (x, y, z) |a| = √(x² + y² + z²) a·b = x₁x₂ + y₁y₂ + z₁z₂

🎲 Вероятность

Вероятность — мера возможности наступления события. Число от 0 до 1.
ОпределениеP(A) = m/n m — благоприятные исходы n — все исходы 0 ≤ P(A) ≤ 1
Пример: Вероятность выпадения 3 на кубике: P = 1/6
Противоположное событиеP(Ā) = 1 - P(A)
СложениеP(A ∪ B) = P(A) + P(B) - P(A ∩ B) Несовместные: P(A ∪ B) = P(A) + P(B)
УмножениеP(A ∩ B) = P(A)·P(B|A) Независимые: P(A ∩ B) = P(A)·P(B)
Условная вероятностьP(B|A) = P(A ∩ B)/P(A)

РазмещенияA(n,k) = n!/(n-k)!

СочетанияC(n,k) = n!/(k!(n-k)!) C(n,k) = C(n,n-k) C(n,0) = C(n,n) = 1

🔗 Прогрессии

Прогрессия — последовательность чисел, где каждое следующее получается по определённому правилу.

Арифметическая прогрессия

Каждое следующее число больше предыдущего на одно и то же число d.
aₙ = a₁ + (n-1)d Sₙ = n(a₁ + aₙ)/2 Sₙ = n(2a₁ + (n-1)d)/2 aₙ = (aₙ₋₁ + aₙ₊₁)/2
Пример: 2, 5, 8, 11, ... d = 3 a₅ = 2 + 4·3 = 14

Геометрическая прогрессия

Каждое следующее число больше предыдущего в q раз.
bₙ = b₁·qⁿ⁻¹ Sₙ = b₁(qⁿ - 1)/(q - 1), q ≠ 1 S = b₁/(1 - q), |q| < 1 bₙ² = bₙ₋₁ · bₙ₊₁
Пример: 3, 6, 12, 24, ... q = 2 b₅ = 3·2⁴ = 48
